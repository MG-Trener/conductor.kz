# CONDUCTOR mobile

Внутреннее мобильное приложение для работы с продажами CONDUCTOR.KZ. Оно живёт отдельно от публичной витрины сайта и после слияния ветки будет доступно по адресу `https://conductor.kz/mobile/`.

## Что уже реализовано

- вход сотрудников через Firebase Authentication (Email/Password);
- рабочий дашборд: продажи за сегодня, новые и активные заказы, низкие остатки;
- быстрый заказ клиента;
- каталог DM30, DM60, DM90 и красок Холи;
- автоматический расчёт суммы;
- создание заказа и списание товара одной Firestore-транзакцией;
- статусы заказа: новый → подтверждён → отправлен → готово, а также отмена;
- склад с быстрыми корректировками остатков;
- realtime-обновление между устройствами;
- постоянный локальный Firestore-кэш (IndexedDB);
- PWA: можно установить на главный экран Android как отдельное приложение.

## Первое подключение Firebase

1. В Firebase Console откройте **Project settings → Your apps**.
2. Если Web App ещё не создан, создайте его для `conductor.kz`.
3. Скопируйте объект `firebaseConfig`.
4. Откройте `/mobile/` — при первом запуске приложение предложит вставить этот объект. Конфигурация сохранится локально на устройстве.
5. Когда конфигурация будет окончательно утверждена, её можно записать в `mobile/firebase-config.js`, чтобы не вводить на каждом устройстве.

Firebase Web Config не является серверным секретом. Никогда не помещайте в клиентский код service-account JSON, private keys или admin credentials.

## Authentication

В Firebase Console включите **Authentication → Sign-in method → Email/Password**.

Публичной регистрации в приложении нет. Учётные записи сотрудников создаются администратором проекта Firebase.

## Firestore

Создайте Cloud Firestore. Правила находятся в корневом файле `firestore.rules`.

Минимальные коллекции создаются приложением автоматически после первого успешного входа:

- `products` — товары, цены и остатки;
- `orders` — заказы и история их статусов.

Начальные товары:

| Код | Товар | Цена |
| --- | --- | ---: |
| DM30 | Цветной дым DM30 | 2 500 ₸ |
| DM60 | Цветной дым DM60 | 3 000 ₸ |
| DM90 | Цветной дым DM90 | 3 500 ₸ |
| HOLI | Краска Холи | 1 000 ₸ |

Начальный остаток каждого товара равен `0`: фактическое количество нужно внести на экране **Склад**.

## Правила доступа

Текущая первая версия разрешает работу с `products` и `orders` только пользователям, которые уже вошли через Firebase Authentication. Остальная база закрыта. Это подходит для внутреннего приложения без публичной регистрации.

Перед добавлением разных ролей сотрудников правила нужно расширить ролями/Custom Claims, а не открывать Firestore публично.

## Установка на Android

После публикации откройте `https://conductor.kz/mobile/` в Chrome и выберите **Установить приложение** / **Добавить на главный экран**. Приложение запускается отдельно от браузера в портретном режиме.
