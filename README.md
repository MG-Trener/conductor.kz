# conductor.kz

Одностраничный сайт CONDUCTOR — цветные дымы и краски Holi.

## Публикация

Публичный сайт рассчитан на GitHub Pages из ветки `main`, корень репозитория.

Пользовательский домен: `conductor.kz`.

## Мобильное рабочее приложение

В каталоге `mobile/` находится внутреннее мобильное PWA для сотрудников CONDUCTOR: заказы, быстрые продажи и склад. Backend — Firebase Authentication + Cloud Firestore.

После публикации приложение доступно отдельно от витрины по адресу `https://conductor.kz/mobile/` и может быть установлено на Android с главного экрана браузера.

Инструкция по Firebase и структуре данных: `mobile/README.md`.
